# KAF-3 — Assured

**Nivel enterprise con certificaciones externas.**

---

## Requisitos

KAF-3 = KAF-2 + los siguientes controles:

| Control | Descripción |
|---|---|
| **KAF-6.1** | ISO 27001 vigente |
| **KAF-6.2** | SOC 2 Type II (auditado en últimos 12 meses) |
| **KAF-6.3** | Pentesting anual documentado |
| **KAF-6.4** | HSM para claves privadas |
| **KAF-6.5** | Arquitectura Zero Trust |
| **KAF-7.1** | GDPR compliance documentado |
| **KAF-8.1** | Backups diarios con retención ≥30 días |
| **KAF-8.2** | Disaster recovery plan probado |
| **KAF-8.3** | SLA ≥99.5% sostenido |
| **KAF-9.3** | Rotación de claves cada ≤90 días |
| **KAF-9.4** | TLS 1.3 obligatorio |
| **KAF-10.2** | No almacenamiento de datos de tarjeta |
| **KAF-10.3** | Webhooks firmados con HMAC |
| **KAF-12.3** | Políticas documentadas (acceso, cifrado, incidentes) |

**Total: 29 controles acumulados.**

---

## Proceso

1. El agente ya tiene KAF-2.
2. Se presenta evidencia de ISO 27001, SOC 2 Type II y pentesting.
3. Auditoría externa de los 14 controles adicionales.
4. Emisión de certificado KAF-3 por auditor acreditado.
5. Publicación en registro público + notificación al cliente.

**Tiempo:** 2-4 semanas (incluye auditoría externa).
**Costo:** €4.900 auditoría única + €1.900/año de mantenimiento.
**Válido por:** 12 meses.

---

## Qué certifica

- Seguridad de nivel enterprise.
- Certificaciones internacionales vigentes.
- Procesos operativos auditados.
- Preparación para clientes Fortune 500.

**Cumple:** EU AI Act + ISO 27001 + SOC 2 + GDPR.

---

## Dirigido a

- Empresas con clientes enterprise.
- Startups en Serie A/B.
- Proveedores de servicios financieros.

---

## Renovación

Anual. Requiere:
- Re-auditoría de los 14 controles.
- Evidencia de incidentes (o ausencia).
- Actualización de certificaciones ISO/SOC 2.
