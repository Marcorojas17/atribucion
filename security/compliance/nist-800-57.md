# NIST SP 800-57 — Gestión de claves

## Estado

✅ **Implementado.**

Atribución sigue las recomendaciones de NIST SP 800-57
para el ciclo de vida de claves criptográficas.

## Qué certifica

NIST Special Publication 800-57: Recommendation for Key Management.
Guía estándar para generar, distribuir, almacenar, usar,
rotar y destruir claves criptográficas.

## Ciclo de vida de claves

### 1. Generación
- **Algoritmo:** ECDSA secp256k1 (clásico) + ML-DSA-65 (post-cuántico)
- **Entropía:** fuente segura del sistema operativo
- **Validación:** verificación matemática post-generación

### 2. Distribución
- **Clave pública:** publicada en DID Document
- **Clave privada:** nunca sale del HSM (o almacenamiento seguro)
- **Intercambio:** TLS 1.3 con ML-KEM híbrido

### 3. Almacenamiento
- **Clave privada:** HSM o cifrada con AES-256-GCM
- **Clave pública:** almacenamiento público
- **Metadatos:** cifrados con clave separada

### 4. Uso
- **Firma:** solo para firmar payloads canónicos
- **Verificación:** siempre contra clave pública
- **Auditoría:** cada uso registrado

### 5. Rotación
- **Frecuencia:** cada 90 días
- **Automática:** sí
- **Notificación:** 7 días previos
- **Solapamiento:** 30 días (transición)

### 6. Destrucción
- **Método:** sobreescritura + eliminación segura
- **Auditoría:** registro de destrucción
- **Retención histórica:** claves archivadas (sin uso)

## Cripto-periodos

NIST define cripto-períodos según el tipo de clave:

| Tipo de clave | Cripto-período |
|---|---|
| Firma privada (uso) | 1-3 años |
| Firma privada (raíz) | 10-20 años |
| Cifrado simétrico | 1-2 años |
| Certificados TLS | 1 año (máximo) |
| Firma de código | 3-5 años |

## Algoritmos aprobados (NIST)

### Firma
- ECDSA P-256, P-384, P-521
- Ed25519
- RSA-PSS (2048+ bits)
- ML-DSA (Dilithium) — post-cuántico
- SLH-DSA (SPHINCS+) — post-cuántico

### Hash
- SHA-256, SHA-384, SHA-512
- SHA3-256, SHA3-384, SHA3-512
- BLAKE2, BLAKE3

### Cifrado simétrico
- AES-128, AES-192, AES-256
- ChaCha20-Poly1305

### Intercambio de claves
- ECDH (P-256+)
- X25519
- ML-KEM (Kyber) — post-cuántico
